# BINSHOT — その一投に、すべてを。

一人称3Dのゴミ投げゲームです。Three.js 0.170.0で描画し、cannon-es 0.20.0で重力・接触・跳ね返り・回転を120Hzで計算します。依存ライブラリは同梱済みで、実行時にCDN・APIキー・有料画像生成サービスは使いません。

## 遊び方

1. ステージを開始する。最初のステージは8投で2回成功が目標。
2. 画面のドラッグ、または「左右」「角度」で狙いを合わせる。
3. POWERを調整して「投げる」。最初の丸めた紙は24%が一つの目安。
4. 別のゴミになったら強さを調整する。軽いゴミほど風の影響が強い。
5. 成功時のスロー・効果音・紙吹雪を楽しみ、リプレイで確かめる。

「操作：スワイプ」にすると画面上の上向きスワイプで直接投げます。上方向の距離は角度、速度は強さ、横方向のずれは狙いに加算されます。調整モードなら指の速度に左右されず、パラメーターを細かく変更できます。

PC操作：Spaceで投球、左右キーで照準、上下キーで角度、+/-で強さ、1〜4で投げ方、Rでリプレイ、Escで一時停止。Shift併用で照準の調整を細かくできます。スライダーにフォーカス中は、矢印キーがそのスライダーを操作します。

## 内容

- 12ステージ。オフィス、公園、屋上の3環境。
- 丸めた紙、ペットボトル、空き缶、ティッシュ、紙コップ、お菓子の箱の6種。通常プレーでは同じゴミが続きません。
- オーバー、山なり、アンダー、ライナーの4投法。強さ・左右・角度・回転を調整可能。
- 横風、向かい風、時間変化する風、通行人、動くゴミ箱、自動で左右に歩くプレイヤー。
- 通行人・ゴミ箱の縁・側面・底・床との物理的な衝突。
- 成功が近そうな瞬間のスローモーション。演出中も物理時間と障害物の時間は同じ倍率で進みます。投球の軌道を成功側へ補正しません。
- 120Hzで記録するリプレイ。ゴミ箱側／プレイヤー側の視点、速度変更、シーク、一時停止。
- フリープレーは全12ステージを最初から選択可。ゴミ、風、環境の動きを固定可能。投球数は無制限。
- 進行とベストスコアはブラウザーのlocalStorageに保存。端末やブラウザー間では同期しません。リプレイは直前の1投をメモリー内に保持します。

空気抵抗や物体サイズは、遊びやすさを考慮したゲーム用の値です。ティッシュは柔軟体シミュレーションではなく、空気抵抗の強い軽量剛体として扱います。ゲーム内の短い点線は、投球出だしの参考であり、最終着地点の保証ではありません。

## 起動

公開されたURLをSafari / Chromeで開きます。WebGL 2対応ブラウザーが必要です。iPhoneではファイルアプリのHTMLプレビューではなく、HTTPSのURLをSafariで開いてください。音は最初のタップ後に有効になります。iPhoneの消音設定・音量によっては聞こえない場合があります。

開発用にはPython 3があれば起動できます。

```bash
python3 -m http.server 8080 --directory dist
```

ブラウザーで http://localhost:8080/ を開きます。`file://`から複数ファイル版を開くとES Modulesの制約があるためHTTPサーバーを使います。

## ファイルと公開

- `dist/`：そのまま公開できる完成ゲーム。ビルド不要。
- `dist/guide.html`：GitHubとCloudflare Accessによる限定公開の手順。
- `DEPLOY-JA.md`：同じ公開手順のテキスト版。
- `tests/physics.test.mjs`：物理挙動の自動検証。
- 別途用意する「BINSHOT-play.html」はライブラリ・CSSを内蔵した1ファイル版です。`index.html`へ改名し、GitHubに1つだけアップロードする方法も公開手順に記載しています。

GitHubをPrivateにする設定と、CloudflareのゲームURLをアクセス制限する設定は別です。限定公開する場合は、公開手順のAccess設定と未ログイン状態の確認まで行ってください。

## 検証

Node.js 18以降で追加インストールなしに実行できます。

```bash
npm test
npm run check
```

制作時のブラウザー確認環境ではWebGLが無効だったため、3D画面の実描画、スマートフォン実機の速度、音・操作感の確認は未実施です。物理挙動と構文を自動検証し、結果を`VALIDATION.md`に記載します。
